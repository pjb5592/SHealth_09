## 1. 기본 원칙 및 범위

### 1.1 비즈니스 목표

1. 삼성 헬스에서 수집한 사용자 데이터로 **연령대별(20·30·40·50·60·70대)** BMI 분포 통계를 산출한다.
2. 각 연령대에서 **저체중 / 정상체중 / 과체중 / 비만** 인원 **비율(%)** 을 제공한다.
3. 수집 과정에서 누락된 값(체중 `0`, 기능 개선 후 키 `0`)은 **동일 연령대** 유효 샘플의 평균으로 보정한다.

### 1.2 기술·품질 원칙

| 번호 | 원칙 | 설명 |
|------|------|------|
| P-01 | 도메인 우선 | BMI 공식·4단계 분류·연령 구간·보정 규칙은 README·`bmi.png`와 일치해야 한다. |
| P-02 | 동작 보존(1차 리팩토링) | 요구사항 변경 없이 구조만 개선할 때는 `SHealthBMI` 출력(또는 baseline)과 동일해야 한다. |
| P-03 | 경계값 명시 | BMI `18.5`, `23`, `25` 및 연령 구간 경계(`19/20/29/30` 등)는 결함·TC에서 반드시 검증한다. |
| P-04 | 단일 책임(SRP) | CSV 로딩, 보정, BMI 계산, 분류, 연령대 집계, 조회 API는 분리 대상이다 (Activities 4). |
| P-05 | 테스트 후행 | 0~6단계는 빌드·수동 검증 중심; Google Test 전면 적용은 **8단계(TDD)** 에서 수행한다. |

### 1.3 범위(In / Out)

| 구분 | 포함 | 제외(현 README 기준) |
|------|------|----------------------|
| In | `shealth.dat` CSV 로드, 체중 0 보정, BMI·4단계 분류, 20~70대(10년 단위) 비율, `getBmiRatio` | DB·네트워크·UI |
| In (Activities 4) | 키 0 보정, 정상 BMI 사용자 목록, 전체 대비 범주 비율, SRP 리팩토링 | |
| Out | 10대·80대 이상 전용 통계(별도 요구 없음) | 연령대 외 사용자는 집계 대상에서 제외될 수 있음 |
| Out | 파일 형식 검증·인증·다국어 리포트 | |

### 1.4 연령대 정의

- 지원 연령대 클래스: **20, 30, 40, 50, 60, 70** (10년 단위 표기).
- 구간: **`[ageClass, ageClass + 10)`** (하한 포함, 상한 미포함).

| 연령대 표기 | `ageClass` | 나이 `age` 조건 |
|-------------|------------|-----------------|
| 20대 | 20 | `20 ≤ age < 30` |
| 30대 | 30 | `30 ≤ age < 40` |
| 40대 | 40 | `40 ≤ age < 50` |
| 50대 | 50 | `50 ≤ age < 60` |
| 60대 | 60 | `60 ≤ age < 70` |
| 70대 | 70 | `70 ≤ age < 80` |

## 3. BMI 계산 및 4단계 분류 기준

### 3.1 BMI 계산

| 항목 | 내용 |
|------|------|
| 공식 | \(\text{BMI} = \dfrac{\text{체중(kg)}}{\text{키(m)}^2}\) |
| 입력 키 | cm |
| 변환 | \(\text{키(m)} = \text{키(cm)} / 100.0\) |
| 구현 예 | `bmi = weight / ((height / 100.0) * (height / 100.0))` |

### 3.2 4단계 분류 (한국 기준)

README 문구와 `bmi.png` 시각 기준을 병기한다. **경계값 해석이 다르면 결함 분석(4단계)에서 확정**한다.

| 구분 | README.md | `bmi.png` | 권장 확정 기준(테스트 설계용) |
|------|-----------|-----------|------------------------------|
| 저체중 | 18.5 **이하** | BMI **< 18.5** | README 우선: **BMI ≤ 18.5** |
| 정상체중 | 18.5 **초과** & 23 **미만** | **18.5 ≤** BMI **< 23** | README 우선: **18.5 < BMI < 23** |
| 과체중 | 23 **이상** & 25 **미만** | **23 ≤** BMI **< 25.00** | **23 ≤ BMI < 25** |
| 비만 | 25 **이상** | BMI **≥ 25.00** | **BMI ≥ 25** |

### 3.3 경계값 매트릭스 (권장 확정 기준)

| BMI 값 | 분류 |
|--------|------|
| &lt; 18.5 | 저체중 |
| 18.5 | 저체중 (README) / 정상 (`bmi.png`) → **README 기준 저체중** |
| 18.500…1 ~ 22.999… | 정상체중 |
| 23.0 ~ 24.999… | 과체중 |
| 25.0 | 비만 |
| &gt; 25 | 비만 |

> **현행 코드 참고(결함 후보)**: `SHealth.cpp`는 비만을 `bmis[i] > 25`로 처리하여 **BMI = 25.0이 어떤 범주에도 포함되지 않을 수 있음**. 4단계 결함 분석·TC에서 수정 여부를 판단한다.

### 3.4 분류 의사코드 (요구사항)

```
if (bmi <= 18.5)           → 저체중
else if (bmi < 23)         → 정상체중
else if (bmi < 25)         → 과체중
else                       → 비만
```

## 4. 체중 누락(0) 연령대 평균 보정

### 4.1 보정 규칙

| 항목 | 내용 |
|------|------|
| 트리거 | `weight == 0.0` (부동소수점 동등 비교 `== 0.0`) |
| 보정값 | **동일 연령대**에서 `weight != 0` 인 레코드 체중의 **산술 평균** |
| 적용 시점 | BMI 계산 **이전** |
| 연령대 루프 | `ageClass = 20, 30, …, 70` (step 10), 구간 `[ageClass, ageClass+10)` |

### 4.2 처리 절차

| 단계 | 동작 |
|------|------|
| 1 | 연령대 `a`별로 `weight != 0` 인 멤버의 `sum`, `count` 집계 |
| 2 | `weight == 0` 인 멤버에 `weight = sum / count` 대입 |
| 3 | 전 연령대 보정 완료 후 BMI 계산 |

### 4.3 예외·엣지 케이스

| 상황 | 기대 동작(요구 정의) | 비고 |
|------|----------------------|------|
| 연령대 내 유효 체중 1건 이상 | 0인 레코드만 평균으로 치환 | 정상 경로 |
| 연령대 내 **전원** `weight == 0` | `count == 0` → **0으로 나누기** 위험 | TC·결함 목록 필수 |
| 연령대 외 나이 | 해당 연령대 평균 집계·보정 대상 아님 | |
| 보정 후 BMI | 치환된 체중으로 계산 | |

### 4.4 키 누락(0) 보정 (Activities 4 — 기능 개선)

| 항목 | 내용 |
|------|------|
| 트리거 | `height == 0.0` |
| 보정값 | 동일 연령대 `height != 0` 평균 (cm) |
| 적용 시점 | BMI 계산 이전 (체중 보정과 순서·결합 방식은 설계 시 명시) |
| 엣지 | 전원 `height == 0` → 0 나누기·BMI 무한대 방지 TC 필요 |

## 5. 연령대별 저체중/정상/과체중/비만 비율 산출

### 5.1 집계 규칙

| 항목 | 규칙 |
|------|------|
| 대상 | 각 `ageClass` 구간에 속하는 사용자 |
| 분모 `sum` | 해당 연령대 **전체 인원 수** (보정 후 BMI 기준) |
| 분자 | 4단계 분류별 인원 수 |
| 비율 단위 | **퍼센트(%)** — `(인원 / sum) * 100.0` |
| 저장 | 연령대·범주별 `double` (현행: 멤버 변수 24개) |

### 5.2 산출 예시 (개념)

연령대 20대, 인원 100명, 저체중 10명 → 저체중 비율 = `10.0` (%).

### 5.3 일관성 요구

| 번호 | 요구 |
|------|------|
| R-01 | 한 연령대에서 4개 범주 인원 합 = `sum` (분류 상호 배타·전체 포괄일 때). |
| R-02 | 4개 비율 합 ≈ 100.0 (부동소수점 오차 허용 범위는 TC에서 `EXPECT_NEAR`로 정의). |
| R-03 | `sum == 0` (해당 연령대 무인원) 시 0 나누기 방지 동작 정의 필요. |

### 5.4 전체 사용자 대비 비율 (Activities 4)

| 항목 | 내용 |
|------|------|
| 목적 | 연령대가 아닌 **전체 로드 사용자** 기준 4범주 비율 |
| 분모 | 전체 `count` (또는 유효 BMI 사용자 수 — API 설계 시 명시) |
| 산출 | README Activities 4 — 신규 API 또는 메서드로 제공 |

## 6. `getBmiRatio(ageClass, type)` API 계약

### 6.1 시그니처 (현행)

```cpp
double getBmiRatio(int ageClass, int type);
```

### 6.2 매개변수

| 매개변수 | 허용 값 | 의미 |
|----------|---------|------|
| `ageClass` | `20`, `30`, `40`, `50`, `60`, `70` | 연령대 클래스 (구간 하한) |
| `type` | `100`, `200`, `300`, `400` | BMI 범주 코드 |

### 6.3 `type` 코드표

| `type` | 범주 | 반환 값 |
|--------|------|---------|
| 100 | 저체중 | 해당 연령대 저체중 **비율(%)** |
| 200 | 정상체중 | 정상 **비율(%)** |
| 300 | 과체중 | 과체중 **비율(%)** |
| 400 | 비만 | 비만 **비율(%)** |

### 6.4 반환·오류 계약

| 조건 | 반환 |
|------|------|
| 유효 `(ageClass, type)` | `calculateBmi` 수행 후 집계된 비율 (`double`, %) |
| 미지원 `ageClass` 또는 `type` | `0.0` (현행 구현) |
| `calculateBmi` 미호출 | 정의되지 않음 — **호출 전제: 먼저 `calculateBmi` 성공** |

### 6.5 선행 조건·사용 순서

1. `int n = calculateBmi("shealth.dat");` — 파일 로드·보정·집계.
2. `getBmiRatio(20, 100)` 등으로 연령대별 비율 조회 (`SHealthBMI.cpp` 참고).

### 6.6 관련 API (현행)

| API | 역할 |
|-----|------|
| `int calculateBmi(const std::string& filename)` | 로드·보정·BMI·연령대 비율 계산; 성공 시 레코드 수, 실패 시 `0` |
| `double getBmiRatio(int ageClass, int type)` | 집계 결과 조회 |
